# ✅ Java To-Do List App

A simple command-line 📋 To-Do List application written in Java. This project was built to reinforce core programming concepts such as loops, user input handling, data structures, and clean code structure.

---

## 🚀 Features

- ➕ Add tasks interactively through the console
- 📃 View your current task list
- ❌ Exit the program cleanly with input validation
- 📚 Easy-to-read menu interface

---

## 🛠 Technologies Used

- 💻 Java (JDK 8+)
- 🧠 Core Java Libraries: `Scanner`, `ArrayList`
- 🏁 Command-line interface (CLI)

---

## ▶️ How to Run

> Compile and execute using a terminal or your favorite IDE (like VSCode, Eclipse, or jGRASP)
